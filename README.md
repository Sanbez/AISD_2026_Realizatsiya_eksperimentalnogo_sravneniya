# Лаборатория сортировок

Статический сайт на HTML, CSS и JavaScript. Серверная часть и база данных не нужны.

## Запуск

В папке проекта выполните:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Локальный HTTP-сервер нужен для Web Worker; открытие `index.html` как файла может не запустить эксперименты.

## Возможности

- Пошаговая визуализация шести сортировок: сравнения, обмены, записи и опорный элемент; управление скоростью и шагами.
- Редактор массива до 80 чисел, генерация и перестановка столбиков перетаскиванием.
- Серии замеров в Web Worker на одинаковых входных данных с сохраняемым seed, прогревом, перемешанным порядком алгоритмов, повторами и ограничением времени.
- Эталонная проверка результата после каждого запуска. Счётчики операций измеряются отдельно от времени.
- График времени и операций, межквартильный разброс, тепловая карта, отношение числа сравнений при удвоении размера.
- История в localStorage, сравнение совпадающих комбинаций, экспорт CSV/JSON/PNG и импорт JSON.
- Задача поиска самого трудного из проверенных порядков и поле для гипотезы и вывода.
- Три готовых исследования с гипотезами, справка о шести алгоритмах и перенос исходного массива из визуализации в эксперимент.
- Наблюдения по измерениям и печатный отчёт с параметрами, гипотезой, графиком, таблицей и выводом. Нажмите «Отчёт / PDF», затем «Печать / сохранить в PDF» и выберите сохранение в PDF в браузере.
- Открытие истории восстанавливает настройки серии; сравнение предупреждает о различиях условий. Последнее удаление можно отменить до обновления страницы. Хранится до 25 серий, поэтому важные данные сохраняйте в JSON.

Измерения отражают скорость конкретного браузера и устройства. Малые значения времени помечаются как недостаточно точные.

- В результатах выберите тип и размер массива: наблюдения относятся к выбранной группе. Легенда включает и скрывает алгоритмы; вид «Столбцы» сравнивает выбранный размер. Нажатие на точку или столбец показывает подробности.
- Вывод сохраняется автоматически в историю браузера. В истории можно задать название серии. Кнопка «На экран» открывает график или визуализацию в режиме демонстрации; для показа сохранённой серии сначала откройте её в истории.
